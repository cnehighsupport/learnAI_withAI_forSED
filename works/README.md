# works — 갤러리 작품 폴더

작품 하나 = 폴더 하나. 폴더 이름은 `연-월-짧은제목` (예: `2026-12-편제표점검도우미`).

```
works/2026-12-편제표점검도우미/
├── meta.json        ← 꼭 필요
├── screenshot.png   ← 화면 캡처 한 장 (없으면 meta.json에 "screenshot": false)
└── index.html       ← 실제로 작동하는 도구일 때만 ("tool": true)
```

## meta.json 형식

```json
{
  "title": "편제표 점검 도우미",
  "team": "중등교육팀",
  "track": 4,
  "summary": "이 도구가 무엇을 해 주는지 한 줄",
  "prompt": "처음에 클로드에게 준 핵심 프롬프트",
  "visibility": "갤러리 공개",
  "date": "2026-12-10",
  "tool": true,
  "screenshot": "screenshot.png"
}
```

- `team`: 중등교육팀 / 국제교육팀 / 진로진학팀 / 과장
- `track`: 0~4 숫자
- `visibility`: 이 저장소에는 **"갤러리 공개"만** 올립니다. 저장소가 공개라서, "과 내부만"·"비공개"는 파일을 올리는 순간 누구나 볼 수 있어요. 그런 작품은 제출 양식으로만 받아 실적에만 셉니다.

## 올리기 전 점검

- 캡처와 파일에 학생·교원 이름, 연락처, 성적, 내부 문서가 보이지 않나요?
- `prompt`에 개인정보나 비공개 자료 원문이 들어 있지 않나요?

## 반영 방식

- 트랙 4 참가자는 GitHub 웹에서 파일을 올리면 변경 요청(Pull Request)이 만들어지고, 담당자가 확인한 뒤 합칩니다. 자동 반영은 없습니다.
- 트랙 0~3은 제출 양식 → 담당자가 이 폴더 구조로 올립니다.
- 갤러리 화면은 GitHub API로 이 폴더 목록을 읽습니다. API가 막혔을 때를 대비해 `works/index.json`에도 폴더 이름을 한 줄 추가해 두세요.
